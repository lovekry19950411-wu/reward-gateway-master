# WLD Treasure MVP 30-60-90 Roadmap

## North Star

Do not build lending first.

Validate this funnel first:

```text
Play
-> Accumulate
-> Verify
-> Join Pool
-> Qualify
-> Later Lending
```

Final long-term direction:

```text
Traffic
-> Identity
-> High-intent users
-> Lending product
```

Current validation question:

```text
Will users stay, verify, join the WLD reward pool, and come back?
```

## Phase 1: Weeks 1-2

Goal: Build a playable H5 MVP home experience.

Main screens:

- Home
- Quest
- Treasure
- Profile
- Admin

Home cards:

- Today Tasks
- Open Treasure Box
- Lucky Pool
- Join Waitlist

Quest:

- Daily Login: +10 points
- Share: +20 points
- Invite: +50 points

Treasure:

- Open box
- Rewards: Points, Keys, Tickets

Profile:

- Status
- Points
- Keys
- Tickets

Admin:

- API Test
- Audit
- Roadmap

Done when:

- Guest can enter
- Tasks can be completed
- Points can accumulate
- Treasure box can be opened

## Phase 2: Weeks 3-4

Goal: Add the identity upgrade funnel.

Identity stages:

```text
Guest
-> Active User
-> Verified User
-> Qualified User
```

Rules:

- Guest: points below 30
- Active User: points >= 30
- Verified User: World ID completed
- Qualified User: verified, points > 100, and joined pool

Done when:

- Status upgrades automatically
- World ID can be connected
- Airtable stores the funnel data

## Phase 3: Month 2

Goal: Test the Treasure Pool.

Pool rule:

```text
0.1 WLD = 1 Ticket
```

Ticket utility:

- Weekly Draw
- Treasure box boost
- Airdrop weight

Pool split:

- 70% player rewards
- 20% platform
- 10% growth fund

Language rules:

- Do not promise APR
- Do not promise guaranteed yield
- Use "Lucky Rewards" and "event reward pool"

Done when:

- Users can convert WLD intent into tickets
- Weekly draw can be recorded
- Pool history is visible

## Phase 4: Month 3

Goal: Validate lending demand without launching lending.

Do not build:

- Borrow Now

Build:

- Lending Interest Form

Form fields:

- I have WLD
- I am willing to collateralize WLD
- I want to borrow stablecoins
- Desired borrow amount

Done when:

- 100+ Qualified Users
- 20-30 users express borrow intent

## MVP KPI

Month 1:

- 100-300 registrations
- 30% return rate
- 50 verified users
- 20 qualified users

Month 2:

- 500-1000 users
- 100+ pool participants

Month 3:

- 20-30 borrow intent submissions

## One-line Strategy

```text
Do not start with lending.
Start with play, accumulation, verification, pool participation, qualification, then lending.
```
